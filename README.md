## Описание программы

Expense Tracker — это десктопное приложение с графическим интерфейсом для учёта личных расходов. Оно позволяет добавлять траты с указанием суммы, категории и даты, фильтровать записи по категории и дате, а также подсчитывать сумму расходов за выбранный период. Данные сохраняются в JSON-файл, что обеспечивает их сохранность между сеансами работы.

## Как использовать

1. Убедитесь, что на вашем компьютере установлен Python 3.6 или выше.
2. Запустите скрипт `expense_tracker.py` (или любой другой файл, содержащий код).
3. Откроется главное окно приложения.

### Добавление расхода
- В верхней панели введите **сумму** (положительное число), выберите **категорию** из списка, укажите **дату** в формате `ГГГГ-ММ-ДД`.
- Нажмите кнопку **«Добавить расход»** — запись появится в таблице.

### Фильтрация и подсчёт суммы
- В панели «Фильтры и сумма за период» выберите **категорию** (или «Все»), при необходимости укажите начальную и конечную дату.
- Нажмите **«Применить фильтр»** — таблица покажет только подходящие записи, а ниже отобразится их общая сумма.
- Кнопка **«Сбросить фильтр»** отключает все фильтры и показывает все расходы.

### Редактирование и удаление
- Выделите строку в таблице и нажмите **«Редактировать»** — откроется окно для изменения суммы, категории или даты.
- Нажмите **«Удалить»** для удаления выбранной записи (с подтверждением).

### Сохранение данных
- Все изменения автоматически сохраняются в файл `expenses.json` в папке с программой.

## Примеры использования (тесты)

### Пример 1: Добавление расхода
1. Сумма: `150.50`, категория: `Еда`, дата: `2025-03-15`.
2. Нажать «Добавить расход».  
   **Результат:** В таблице появилась новая строка.

### Пример 2: Фильтр по категории
1. Добавить несколько расходов с разными категориями.
2. В фильтре выбрать категорию `Транспорт`, нажать «Применить фильтр».  
   **Результат:** Показаны только транспортные расходы, сумма обновлена.

### Пример 3: Фильтр по диапазону дат
1. Добавить расходы с датами `2025-03-01`, `2025-03-10`, `2025-03-20`.
2. Установить «Дата с» = `2025-03-05`, «по» = `2025-03-15`.  
   **Результат:** Показан расход от `2025-03-10`, сумма = его значению.

### Пример 4: Некорректный ввод
1. Сумма: `-50`, нажать «Добавить расход».  
   **Результат:** Появляется сообщение об ошибке «Сумма должна быть положительным числом». Расход не добавляется.

### Пример 5: Неверный формат даты
1. Дата: `15.03.2025`, нажать «Добавить расход».  
   **Результат:** Ошибка «Дата должна быть в формате ГГГГ-ММ-ДД».
